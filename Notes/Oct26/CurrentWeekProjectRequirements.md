Mein aik ASP.NET Core MVC app banana chahata ho. Meri requirements yeah hein

1 - Server-Side (Backend): Mein server se aik PPTX (PowerPoint) file aur kuch images ka data ekthay (simultaneously) client browser ko bhejna chahtaa hoon.

2 - Client-Side (Frontend UI): Browser per jab yeh data pohnchay, to UI ka behavior yeh hona chahiye:
- Jo images aayi hain, wo screen per display (show) ho jayen.
- Screen per aik download button ho, jis per user click karay to wo PPTX file download ho jaye.
