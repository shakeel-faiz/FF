Frontend Components (Jo User Ko Dikhta Hai)**Yeh website ka woh hissa hai jise user dekhta hai aur uske sath interact karta hai.

*   **Header & Navigation Bar:** Website ka sab se upar wala hissa jahan logo aur menu (Home, About, Contact) hota hai.
    
*   **Hero Section:** Website ka main welcome area jo bara aur attractive hota hai, is mein aam tor par ek barha heading aur button hota hai.
    
*   **Main Content Area:** Jahan aap ki website ki asli maloomat, images, videos, ya articles hotae hein.
    
*   **Sidebar:** Ek chota column jo website ke side par hota hai (aam tor par blogs mein links ya ads ke liye).
    
*   **Footer:** Website ka sab se neechay wala hissa jahan copyright maloomat, social links, aur privacy policy hoti hai.
    
*   **Forms:** User se maloomat lene ke liye login, signup, ya contact forms.

Phase 1: Static Layout Components (HTML & CSS Only)

Start here to learn how to structure content and style it. \[[1](https://www.codechef.com/roadmap/html), [2](https://www.udemy.com/course/html-css-made-easy-web-design-front-end-web-development/?srsltid=AfmBOorPggXeK_sL6M19PECmDejL2N7ZJjECAB-SyV2rqA2L_w5scBw-), [3](https://www.codesuccess.net/learn-to-code)\]

-   Buttons & Links: Creating clickable actions and styling hover effects.
-   Typography Blocks: Structuring paragraphs, headings, and lists properly.
-   Card Component: A box containing an image, title, text, and button (the building block of most webs).
-   Header / Navbar: Creating a top navigation menu with a logo and links.
-   Footer: Designing the bottom area with copyright text and columns of links.
-   Contact Form: Structuring input fields, textareas, checkboxes, and labels. \[[1](https://intellipaat.com/blog/what-is-css/), [2](https://www.youtube.com/watch?v=WqUZ6DJubgE), [3](https://agilie.com/blog/effective-layout-testing-tools), [4](https://www.outcrowd.io/blog/hierarchy-in-design-invisible-control), [5](https://foldingburritos.com/blog/product-prioritization-techniques/)\]

Phase 2: Responsive & Layout Components (Flexbox & Grid)

Learn how to make components adjust to mobile and desktop screens. \[[1](https://www.udemy.com/course/master-front-end-web-development-build-3-portfolio-projects/?srsltid=AfmBOoomeyAbdVh0WUNdOC55H2r0CVNr4g-x_-56qSUB0nAiclCuEJwk), [2](https://www.linkedin.com/top-content/design/app-design-layouts/responsive-layout-strategies/), [3](https://www.instagram.com/reel/DVvobuFjfMR/)\]

-   Responsive Multi-column Grid: Arranging a collection of cards that shift from 1 column on mobile to 3 columns on desktop.
-   Hero Section: A full-width banner at the top of a page with background images and centered text.
-   Pricing Table: Comparing free, pro, and enterprise tiers side-by-side.
-   Sidebar: A collapsible side navigation menu. \[[1](https://pwskills.com/blog/web-development/bootstrap-cards-media-objects-and-examples), [2](https://1to100.com/baseplate/developer-guide/baseplate-user-interface-paradigms/), [3](https://ishadeed.com/article/grid-layout-flexbox-components/), [4](https://launchthedamnthing.com/blog/stop-following-web-design-trends-in-2025), [5](https://www.youtube.com/watch?v=0bGqVW7PI3U)\]

Phase 3: Interactive Components (Basic JavaScript)

Add animation and functionality to your elements. \[[1](https://elementor.com/blog/how-to-design-a-website-guide/), [2](https://www.themexpert.com/blog/framer-button-components-from-basic-to-complex), [3](https://medium.com/@iamryanyu/front-end-checklist-for-component-development-3d03df064886)\]

-   Mobile Hamburger Menu: A menu button that opens and closes the navigation drawer on mobile.
-   Modal / Pop-up Window: A box that pops up over the content and dims the background when a button is clicked.
-   Image Slider / Carousel: A slideshow component with "Next" and "Previous" arrows.
-   Accordion: Collapsible content blocks often used for Frequently Asked Questions (FAQs).
-   Tabs Component: Switching between different content panels without reloading the page. \[[1](https://blog.frontendpro.dev/10-frontend-projects-to-take-your-coding-skills-to-the-next-level), [2](https://tubikstudio.com/blog/best-practices-for-website-header-design/), [3](https://sparkbox.com/foundry/mobile_navigation_ux_navigation_menu_design_for_content_rich_websites), [4](https://www.upgrad.com/blog/css-project-ideas-topics-for-beginners/), [5](https://help.anthology.com/fb/3.x/Content/Popup.htm)\]

Phase 4: Data-Driven & Advanced Components (Advanced JS / API Integration)

Learn how to handle real-world user data and external information. \[[1](https://www.fomecd.edu.np/syllabuses/BIM%207th%20Semester%20Syllabus%202025.pdf), [2](https://seldomindia.com/building-an-e-book-website-using-javascript-a-step-by-step-guide/), [3](https://www.coursera.org/learn/building-a-complete-mean-stack-application)\]

-   Form Validator: A form that shows real-time error messages if an email is wrong or a password is too short.
-   Search Bar with Filtering: A dynamic input that filters a list of items instantly as the user types.
-   Dark Mode Toggle: A switch that changes the theme of the entire website from light to dark.
-   Infinite Scroll / Pagination: Loading more items or switching pages at the bottom of a list
